# The page contract and project files

## Project layout (made by `short.py init`)
```
videos/<slug>/
  script.json     the plan you write (schema below)
  index.html      the composition: draws any frame from seek(t)
  ch2-*.html      (long-form, optional) more pages: one per chapter, same contract
  kit.js          shared toolkit (copy of $SKILL/engine/kit.js; `short.py kit` refreshes it)
  style.json      the style tokens for this video (edit, then `short.py style <proj> <proj>/style.json`)
  style.css       generated: @font-face + CSS variables (--bg, --ink, --accent, --font-display ...)
  style.js        generated: window.STYLE
  timeline.json   generated by timeline.py (scripts read it)
  timeline.js     generated: window.TIMELINE (the page reads it)
  assets/fonts/   fonts used by the style (OFL/MIT)
  voice/<id>.wav  narration per scene (import_voice.py), optional <id>.words.json
  out/            stills*.png, music.wav, mix.wav, draft.mp4, final.mp4, verify_*.json, verify_sheet_*.png,
                  captions.srt, chapters.txt (long-form), thumbnail.jpg/png, chunks/ (render cache)
```
Never edit the generated files by hand; change `script.json` / `style.json` and re-run.

## script.json
```json
{
  "title": "What is a Kubernetes Pod?",
  "style": "kodekloud-devops",
  "format": "short",
  "fps": 30,
  "captions": { "burn": null },
  "voice": { "mode": "design", "instruct": "female, young adult, moderate pitch, american accent",
             "ref_audio": null, "ref_text": null, "speed": 1.05 },
  "music": { "enabled": false, "mood": "upbeat", "bpm": null, "key": null, "seed": 7, "risers": false, "snap": true, "level_db": null },
  "sfx":   { "enabled": null },
  "pacing": { "lead_in": 0.12, "gap": 0.25, "tail": 0.8, "wps": 2.7 },
  "scenes": [
    { "id": "hook", "say": "Kubernetes never runs your container on its own.", "caption": null,
      "chapter": null, "page": "index.html",
      "min": 2.2, "hold": 0, "pre": 0.08, "accent": false, "transition": null,
      "sfx": "auto", "sfx_at": [ { "word": "fresh", "kind": "pop", "gain_db": 0 } ],
      "visual": "Terminal types the command from frame 0; the container card pops in on 'container'." }
  ]
}
```
| Field | Meaning |
|---|---|
| `format` | `short` (1080×1920), `long` (1920×1080) or `long-4k` (1920×1080 page, 3840×2160 output). Profiles in `engine/formats.json`. |
| `fps` | 30 (default) or 60. Drafts always render at 30 (and at 1080p for 4K). |
| `captions.burn` | Burn captions into the video. `null` = format default (Shorts yes, long-form no; `out/captions.srt` is always written). |
| `voice` | Settings you pass to OmniVoice for every scene (kept here so regenerated lines match). |
| `music.enabled` | `true` **only** when the user asked for music. `mood`/`bpm` default to the style's. `snap` moves scene changes onto half-beats. `level_db` overrides the bed level vs speech (default −9). |
| `sfx.enabled` | `null` = style default, `true`/`false` to force. |
| `pacing` | `lead_in` before the first word, `gap` after each line, `tail` after the last scene, `wps` words/s for estimates without voice. |
| `scenes[].id` | lowercase, digits, `-`/`_`; becomes `#sc-<id>` in the page and `voice/<id>.wav`. |
| `say` | What the narrator says (may contain OmniVoice tags like `[laughter]`). |
| `chapter` | (long-form) starts a YouTube chapter with this title; written to `out/chapters.txt`. |
| `page` | (long-form) which HTML page draws this scene; default `index.html`. Consecutive scenes on one page form a render segment. |
| `caption` | What the captions show if different (`20%` for "twenty percent"). Same word count = word-exact timing. |
| `min` / `hold` | Minimum scene length / extra seconds held after the line. |
| `accent` | A big moment: an impact sound, and (with music) a crash + sub drop on the scene start. |
| `transition` | Override the style's scene transition: `push`, `fade-transform`, `pop`, `punch`, `slide`, `drift`. |
| `sfx` | `auto` (style default on the scene change), `none`, or a kind: `whoosh pop click tick impact riser`. |
| `sfx_at` | Extra sounds on spoken words. |
| `visual` | Your plan for the scene, naming the cue words. Not read by scripts; it's for you and the user. |

## The page rules (`index.html`)
1. **Frame**: `#stage` is exactly `K.W`×`K.H` (1080×1920 or 1920×1080) at 0,0 when the URL has `?render`; set it from JS (`K.st('stage', {width: K.W + 'px', height: K.H + 'px'})`), never hard-code the size. Positions come from a `K.layout({short, long})` table. Without it, the page scales to fit and shows preview controls (play with the real `out/mix.wav`, scrub, safe-zone toggle).
2. **Contract**: define `window.VIDEO = {w, h, duration, fps}` and `window.seek(t)`. `seek` sets **every** visible property from `t`. Any frame must come out right on its own, in any order.
3. **Pure time**: no `Math.random` (use `K.rng(seed)`), no `Date.now`/`performance.now`, no CSS `animation`/`@keyframes`/`transition`, no timers in the render path. The interactive preview lives between `PREVIEW-START` and `PREVIEW-END` comments; the checker ignores that block and it never runs with `?render`.
4. **Anything with history** (a physics sim, a camera that lags) is baked once at load into an array at 1/240 s and read back in `seek`.
5. **Measuring text** (`getComputedTextLength`, `offsetWidth`) only after fonts load: `window.READY = K.ready.then(layout)`. The renderer and checker wait for `window.READY`. Hidden-but-measured elements use `visibility:hidden`, not `display:none` (which measures as 0).
6. **Fonts**: only from `assets/fonts` via `style.css`. The renderer refuses to render with a fallback font.
7. **Layers**: background canvas (`#bg`) → scenes / world → `#captions` → grain (`#grain`) → `#safe` overlay. Keep these ids; the checker and kit use them.
8. **Text marks**: absolutely positioned text gets `white-space:nowrap`. Mark purely decorative text that may sit outside the safe zone with `data-safe-ignore`, and deliberate off-frame text with `data-offscreen-ok`.
9. **Speed**: big CSS `filter: blur()` and huge box-shadows are slow to screenshot. Draw glows/gradients once on a canvas. Blur only during short transitions.

## Two ways to structure a page
- **Scenes** (template, editorial): one `<section class="scene" id="sc-<id>">` per scene and one draw function per id, passed to `K.runScenes({...})`. The style's transition moves sections in and out.
- **One world** (3b1b and KodeKloud demos): objects persist and transform across the whole video; sections stay empty and a single `world(t)` draws everything. Best when the story is one object evolving (an equation, a diagram, a pod moving between nodes).
