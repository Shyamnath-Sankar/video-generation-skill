# fireship-dev: fast developer news (Fireship-inspired)

Dense, witty, fast. A new visual every 1–2 seconds, code on screen, hard cuts that punch in.

## Look
- Dark `#0C0C0F` with a faint 72 px grid, strong vignette, light grain.
- Yellow `#FFC800` is *the* highlight (key words, underlines, the active caption box); orange `#FF6B00` and cyan `#22D3EE` as secondary; red `#E11D48` for "bad".
- Code cards: `#17171D`, JetBrains Mono 30–34 px, syntax colours from the palette, one highlighted line.
- Big labels in Geist 900; tiny mono labels for versions/dates.
- Captions: `box` mode, uppercase, 1–2 words, yellow box behind the active word.

## Motion
- `punch` transition: hard cut on the boundary with a 10% zoom-in that settles fast.
- Inside a scene: quick pops, side-by-side "vs" splits (top/bottom in 9:16), strike-throughs on wrong takes, a meme-speed zoom on the punchline word.
- Pace: change something every 1–1.5 s. Short scenes (2–4 s).

## Recipes
- **"X in 30 seconds"**: name + one-line definition → 3 key features as code snippets → one gotcha → verdict.
- **Version news**: big version number slam → 3 changes as cards → code diff with red/green lines.

## Don't
- The Fireship logo, name, or thumbnail style text. Real company logos unless supplied.
- Invented benchmarks; show relative bars only when the user gives numbers.
